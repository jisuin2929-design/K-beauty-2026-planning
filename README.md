# Kbeauty2026

**2026 건강서울페스티벌 K-뷰티 부스** 소개 홈페이지 (서울특별시약사회)

> K-뷰티의 진짜 매력은 많이 바르는 것이 아니라, 내 피부에 맞는 것을 알고 고르는 것입니다.

빌드 도구 없이 동작하는 모바일 우선 원페이지 정적 사이트입니다. 현장 QR 접속을 고려해 외부 의존성을 최소화했습니다.

## 파일 구조

```
index.html       페이지 뼈대 (섹션 제목, 배치도 SVG, 푸터)
css/style.css    스타일 (색상은 맨 위 :root 변수에서 일괄 변경)
js/content.js    ★ 모든 콘텐츠 문구 (FAQ 8개, 피부 고민 5개, 참여 단계, O/X 등)
js/main.js       동작 (페이지 전환, 아코디언, 검색·필터, 전체 인쇄)
```

## 문서 성격

**상부 보고용 기획안**입니다. 배포용 홈페이지가 아니라, 부스를 어떻게 구성·운영할지 설명하는 것이 목적입니다.
상단 **전체 인쇄** 버튼을 누르면 모든 페이지를 펼친 상태로 순서대로 인쇄(또는 PDF 저장)할 수 있습니다.

## 문구 수정 방법

- 대부분의 문구는 **`js/content.js`** 에 있습니다. 따옴표 안 글자만 바꾸세요.
- 페이지 제목·푸터 문구는 `index.html` 에서 해당 텍스트를 찾아 바꾸면 됩니다.
- 부스 구역 설명은 `boothZones`, 포스터 시각 요소는 `visuals`, 책자 페이지 구성은 `booklet.pages` 에서 수정합니다.

## 특정 질문 바로 열기 (QR 활용)

주소 끝에 `#/faq/q1` ~ `#/faq/q8` 을 붙이면 Q&A 페이지에서 해당 질문이 펼쳐진 상태로 열립니다.
예: `https://<주소>/#/faq/q7` → "약국 화장품과 일반 화장품은 뭐가 다를까?" (예전 형식 `#q7` 도 동작)

## 로컬 미리보기

`index.html` 을 브라우저로 바로 열거나:

```bash
python3 -m http.server 8000   # http://localhost:8000
```
