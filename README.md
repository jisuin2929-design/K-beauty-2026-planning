# Kbeauty2026

**2026 건강서울페스티벌 K-뷰티 부스** 소개 홈페이지 (서울특별시약사회)

> K-뷰티의 진짜 매력은 많이 바르는 것이 아니라, 내 피부에 맞는 것을 알고 고르는 것입니다.

빌드 도구 없이 동작하는 모바일 우선 원페이지 정적 사이트입니다. 현장 QR 접속을 고려해 외부 의존성을 최소화했습니다.

## 파일 구조

```
index.html       페이지 뼈대 (섹션 제목, 배치도 SVG, 푸터)
css/style.css    스타일 (색상은 맨 위 :root 변수에서 일괄 변경)
js/content.js    ★ 모든 콘텐츠 문구 (FAQ 8개, 피부 고민 5개, 참여 단계, O/X 등)
js/main.js       동작 (아코디언, 검색·필터, 피부 고민 선택, 공유·QR)
```

## 페이지 구성

메뉴를 누르면 해당 페이지로 넘어갑니다. 각 페이지는 고유 주소가 있어 QR 코드로 바로 연결할 수 있습니다.

| 주소 | 페이지 | 내용 |
|---|---|---|
| `#/home` | 홈 | K-BEAUTY가 뭐예요? / 핵심 메시지 / 페이지 메뉴 카드 |
| `#/about` | K-뷰티 | 핵심 키워드 4종(상세), 주목받는 이유, 대표 제품군, 기본 루틴·아침/저녁 예시 |
| `#/faq` | Q&A | 8가지 질문 (PART 1/2 탭, 검색, 모두 펼치기) |
| `#/concern` | 피부고민 | 5개 고민별 키워드·관리 팁·상담 안내 + 성분 사전 |
| `#/booth` | 부스안내 | 참여 4단계, 3m×3m 배치도, 구역별 안내, 이용 안내 |
| `#/pharmacy` | 약사상담 | 약국화장품 바로 알기, 질문 예시, 상담 전 준비, 기능성화장품 표시 |
| `#/tips` | O/X | 오해 바로잡기 퀴즈 5문제 |

- 모바일: 상단 가로 스크롤 메뉴 + 하단 고정바 **[홈] [K-뷰티] [Q&A] [피부고민] [부스안내]**
- 각 페이지 하단에 **이전 / 다음** 버튼
- 상단 **공유·QR** 버튼은 지금 보고 있는 페이지 주소로 QR 코드를 만듭니다.
- 메뉴 이름·순서는 `js/content.js` 의 `pages` 에서 바꿀 수 있습니다.

## 부스 배치 (좌측 벽)

안쪽부터 **짐 보관 테이블 → A3 Q&A 책자 → 기념품 테이블(직원 2명)** 순서입니다.
짐 보관 테이블은 좌측 벽과 A3 책자 사이에 두고, 테이블보로 가린 하부에 직원 짐·물품 박스를 보관합니다.

## 문구 수정 방법

- 대부분의 문구는 **`js/content.js`** 에 있습니다. 따옴표 안 글자만 바꾸세요.
- 섹션 제목·푸터 문구는 `index.html` 에서 해당 텍스트를 찾아 바꾸면 됩니다.
- 로고: `index.html` 푸터의 `logo-slot` 부분을 `<img src="..." alt="...">` 로 교체하세요.
- Hero 일러스트: `.hero-visual` 안의 `<svg>` 를 이미지로 교체할 수 있습니다.

## 특정 질문 바로 열기 (QR 활용)

주소 끝에 `#/faq/q1` ~ `#/faq/q8` 을 붙이면 Q&A 페이지에서 해당 질문이 펼쳐진 상태로 열립니다.
예: `https://<주소>/#/faq/q7` → "약국 화장품과 일반 화장품은 뭐가 다를까?" (예전 형식 `#q7` 도 동작)

## 로컬 미리보기

`index.html` 을 브라우저로 바로 열거나:

```bash
python3 -m http.server 8000   # http://localhost:8000
```
