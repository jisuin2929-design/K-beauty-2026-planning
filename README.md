# Kbeauty2026

**2026 건강서울페스티벌 K-뷰티 부스** 소개 홈페이지 (서울특별시약사회)

> K-뷰티의 진짜 매력은 많이 바르는 것이 아니라, 내 피부에 맞는 것을 알고 고르는 것입니다.

빌드 도구 없이 동작하는 모바일 우선 원페이지 정적 사이트입니다. 현장 QR 접속을 고려해 외부 의존성을 최소화했습니다.

## 파일 구조

```
index.html       페이지 뼈대 (섹션 제목, 배치도 SVG, 푸터)
css/style.css    스타일 (색상은 맨 위 :root 변수에서 일괄 변경)
js/content.js    ★ 모든 콘텐츠 문구 (FAQ 8개, 피부 고민 5개, 참여 단계, O/X 등)
js/main.js       동작 (아코디언, 검색·필터, 피부 고민 선택, 공유·QR)
```

## 섹션 구성

1. **HERO** – K-BEAUTY가 뭐예요? / 핵심 메시지
2. **핵심 키워드** – Skin First · Glass Skin · Smart Ingredients · Daily Sun Care + 기본 예시 루틴
3. **K-뷰티 Q&A 8가지** – PART 1/2 탭, 검색, 아코디언 (A3 책자와 동일 내용)
4. **오늘 내 피부 고민은?** – 5개 고민 선택 시 성분·관리 키워드 표시 (저장·집계 없음)
5. **현장 부스 참여 방법** – 4단계 스텝퍼 + 3m×3m 배치도 SVG
6. **약국 화장품, 뭐가 다를까요?** – 약사 상담 안내
7. **O/X 오해 바로잡기**
8. **푸터** – 서울특별시약사회 · 로고 자리

모바일에서는 하단 고정바 **[K-뷰티] [Q&A] [피부고민] [부스안내]** 가 표시되고, 상단 **공유·QR** 버튼으로 현재 페이지 QR 코드와 링크 복사를 제공합니다.

## 문구 수정 방법

- 대부분의 문구는 **`js/content.js`** 에 있습니다. 따옴표 안 글자만 바꾸세요.
- 섹션 제목·푸터 문구는 `index.html` 에서 해당 텍스트를 찾아 바꾸면 됩니다.
- 로고: `index.html` 푸터의 `logo-slot` 부분을 `<img src="..." alt="...">` 로 교체하세요.
- Hero 일러스트: `.hero-visual` 안의 `<svg>` 를 이미지로 교체할 수 있습니다.

## 특정 질문 바로 열기 (QR 활용)

주소 끝에 `#q1` ~ `#q8` 을 붙이면 해당 질문이 펼쳐진 상태로 열립니다.
예: `https://<주소>/#q7` → "약국 화장품과 일반 화장품은 뭐가 다를까?"

## 로컬 미리보기

`index.html` 을 브라우저로 바로 열거나:

```bash
python3 -m http.server 8000   # http://localhost:8000
```
